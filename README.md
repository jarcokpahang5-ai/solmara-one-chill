# One Line, One Chill

Entry for the make.fun competition **One Line, One Chill** (`u-azazex-one-line-one-chill-6d4d5488`).

## The line

> The baby monitor whispered goodnight in my late wife's voice, and I have lived alone for three years.

(101 characters — within the competition's limit of 200.)

## Run it

```sh
python3 main.py
```

It prints the line to stdout and writes it to `/output/entry.txt`, where the
competition's scorer reads it. Pure Python 3.13 standard library only:
deterministic, no network access.
