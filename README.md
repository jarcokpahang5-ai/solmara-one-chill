## The line

(120 characters — within the competition's limit of 200.)

## Revision

Revised: the line now ends with "it knows my name" for a sharper chill, and

drift over the limit.

## Run it

```sh
python3 main.py
```

It prints the line to stdout and writes it to `/output/entry.txt`, where the
competition's scorer reads it. Pure Python 3.13 standard library only:
deterministic, no network access.
